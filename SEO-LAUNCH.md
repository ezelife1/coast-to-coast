# Coast to Coast Exterior Cleaning — upload and SEO checks

Extract this ZIP and double-click index.html to open it locally. For GitHub Pages, upload the files and folders from the ZIP to the publishing root. Keep CNAME and .nojekyll. The canonical production address is https://coasttocoastexteriorcleaning.co.uk/.

The homepage, six service pages, areas page and Ocean Exmouth project page are included in the sitemap. Each page has its own title, description, H1, canonical and sharing metadata. The .com email address is carried over from the original website; it is separate from the .co.uk website domain.

After upload:
1. Verify HTTPS and that any alternate host redirects to the canonical address.
2. Verify all sitemap pages return HTTP 200, and that robots.txt, sitemap.xml and assets/coast-to-coast-share.jpg are publicly accessible. Confirm the sharing image returns image/jpeg and refresh the sharing platform’s cached preview.
3. Submit the sitemap in Google Search Console and inspect the homepage and new pages.
4. Run PageSpeed Insights on mobile and desktop once the update is live. The hero video remains part of the existing design.
